# Trabajo Práctico Integrador - Git y GitHub

## Descripción

Este proyecto forma parte del Trabajo Práctico Integrador del curso Introducción a Git y GitHub para la Gestión de Proyectos Digitales.

El repositorio permite aplicar conceptos básicos de Git y GitHub, como la creación de repositorios, commits, ramas, publicación en GitHub y documentación del proyecto.

## Objetivo

El objetivo es practicar el uso de Git y GitHub mediante la creación, organización, versionado y publicación de un proyecto digital simple.

## Estructura del repositorio

* `README.md`: contiene la descripción y documentación general del proyecto.
* `ENTREGA.md`: registra el proceso de trabajo, los comandos utilizados y los enlaces de entrega.
* `proyecto/`: contiene los archivos principales de la landing page (`index.html` y `styles.css`).
