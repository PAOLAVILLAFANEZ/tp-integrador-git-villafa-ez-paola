Introducción a Git y GitHub para la Gestión de Proyectos Digitales

Sobre el proyecto

Este proyecto forma parte del Trabajo Práctico Integrador del curso Introducción a Git y GitHub para la Gestión de Proyectos Digitales.

El objetivo es aplicar los conocimientos adquiridos sobre control de versiones, repositorios, commits, ramas y colaboración mediante GitHub.

Objetivo

Crear, versionar, documentar y publicar un proyecto digital utilizando Git y GitHub de manera organizada y bajo buenas prácticas.

Conceptos trabajados

  • Creación y gestión de repositorios
  • Registro de cambios mediante commits estructurados
  • Uso de ramas de trabajo (branches)
  • Gestión de Issues y Pull Requests
  • Publicación y sincronización en GitHub
  • Documentación mediante archivos Markdown

Estructura del proyecto

El repositorio contiene la siguiente organización de archivos:

  • README.md: Documentación general del proyecto.
  • ENTREGA.md: Registro del proceso de trabajo y comandos.
  • proyecto/: Archivos principales de la página web (HTML y CSS).
