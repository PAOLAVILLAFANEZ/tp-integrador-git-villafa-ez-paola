Sobre el proyecto

Este proyecto forma parte del Trabajo Práctico Integrador del curso Introducción a Git y GitHub para la Gestión de Proyectos Digitales.

El objetivo es aplicar los conocimientos adquiridos sobre control de versiones, repositorios, commits, ramas y colaboración mediante GitHub.

En este repositorio se aplican conceptos fundamentales relacionados con el control de versiones y la gestión de proyectos mediante Git y GitHub.

🎯

Objetivo

Crear, versionar, documentar y publicar un proyecto digital utilizando Git y GitHub de manera organizada. Crear, versionar, documentar y publicar un proyecto digital utilizando Git y GitHub de manera organizada y bajo buenas prácticas.
